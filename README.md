# AI-phishing-detection-system
## Project overview
Final  year cybersecurity project for detecting, analyzing and responding to AI-generated phishing attacks.

## Project Objectives
- Detect potentially malicious phishing emails and links.
- Alert users when suspicious content is identified.
- Provide mechanisms for reporting phishing attempts.
- Improve user awareness of phishing attacks.
